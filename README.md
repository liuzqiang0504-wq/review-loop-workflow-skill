## Purpose

This skill orchestrates a review loop covering:

- scope definition
- literature search
- download handoff
- PDF processing
- knowledge-base construction
- manuscript drafting
- mock peer review
- targeted revision
- strict final scoring
- Word / Markdown / figure packaging

It enforces one core rule: each workflow stage must declare and use the relevant specialist skill before execution.
